Adaptive Interview Challenge (AI Mock Interview Simulation Bot) - CIE Activity

How to run: unzip and double-click index.html (no server or internet needed).

Features:
- 3 tracks: Web development, Python and data, HR and behavioural
- Adaptive difficulty (Easy/Medium/Hard) based on answer score
- Scoring: keyword coverage 60%, depth 25%, structure 15%
- Hints (-10 points), per-answer feedback, final report

Add questions: edit the BANK object in index.html.
